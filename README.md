# 모의 네이버 폼

QR 피싱 예방 서비스의 해커톤 시연·격리 브라우저 검증용 설문 페이지입니다. 실제 네이버 인증과 연결되지 않습니다.

## 실행

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

저장소 루트에서 실행한 뒤 [로컬 페이지](http://127.0.0.1:8080/)를 엽니다. 설치·빌드는 필요 없으며, 파일을 직접 여는 대신 정적 서버를 사용합니다.

## 시연

1. **설문 참여하기** → 세션 만료 안내 → **로그인하기**.
2. 고정 아이디 `demo_user`에 4자 이상의 더미 비밀번호를 입력하고 **모의 계정으로 로그인**.
3. 3문항 설문을 작성하고 제출하면 완료 화면이 표시됩니다. **처음으로 돌아가기** 또는 새로고침으로 다시 시작합니다.

실제 계정 정보를 입력하지 마세요. 계정 입력값과 설문 응답은 전송·저장하지 않습니다.

분석기로 입력 필드를 검사할 때는 각 컴포넌트의 열린 `shadowRoot` 내부까지 탐색해야 합니다.
